# Moonhaven

A cozy supernatural life-sim with a mystery-driven main story. Think Stardew Valley's warmth and rhythm — farming, friendships, festivals — set in a hidden town where werewolves bake bread, vampires tend bar, and ghosts hold office hours. You arrive with a locket and a half-burned letter, uncover what happened to the witch who founded the town, and choose whether to become one of the supernatural yourself. The mystery pulls you forward; the town is why you stay.

**Engine:** Godot 4.3+ (Standard, GDScript)  
**Platform:** PC (Windows / Mac / Linux)

Design docs live in [`docs/design/master-gdd.md`](docs/design/master-gdd.md). Phase 1 implementation tasks are in [`docs/implementation/phase-1-tasks.md`](docs/implementation/phase-1-tasks.md).

## How to Run

1. Install [Godot 4.3 or newer](https://godotengine.org/download) (Standard edition, not .NET).
2. Open Godot and choose **Import**.
3. Browse to this folder and select `project.godot`.
4. Click **Import & Edit** to open the project.
5. Press **F5** (or click the Play button) once a main scene is set in later tasks.

There is no playable build yet during T-00 — this commit is project scaffolding only.
